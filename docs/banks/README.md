## 各行差异速查

| | 农行 | 建行 | 中行 | 工行 |
|---|---|---|---|---|
| 载体 | HTML，37 张小表按顺序排列 | HTML，容器表里嵌套子表 | PDF（1 页 A4，未加密） | HTML，容器表里嵌套子表（同建行） |
| 一封邮件包含 | 1 张卡 | 1 个账户 | 合并账单（可能多卡） | 1 个账户（可能多卡），每个币种一个账户 |
| 日期格式 | 明细 `YYMMDD`；周期和还款日 `YYYY/MM/DD`（旧模板都是 `YYYYMMDD`） | 明细 `YYYY-MM-DD`；账单日 `YYYY-MM-DD`；周期和还款日 `YYYY/MM/DD` | `YYYY-MM-DD` | 明细 `YYYY-MM-DD`；周期、账单日、还款日 `YYYY年MM月DD日` |
| 明细金额的符号 | **支出为负**（和我们相反） | 还款为负（**和我们一致**） | 没有负号，用"存款/欠款"标签表示方向 | 没有负号，用"(支出)/(存入)"表示方向 |
| 汇总块 | 7 列，含溢缴款和调整 | 4 列 | 按账户类型一行，带方向标签 | 每个币种一行：上期余额、收入、支出、本期余额，**欠款为负** |
| 账单日 | 没有单独写出，等于账单周期的结束日 | 单独写出 | 单独写出 | 单独写出（对账单生成日） |
| 卡号后四位 | 顶部有掩码卡号，每行明细也有 | **只出现在交易行里** | 卡表和卡种行里都有 | 需还款明细、汇总和每行明细里都有 |
