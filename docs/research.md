# 调研与评审留档

## 竞品与前人（2026-09）

| 名称 | 类型 | 取账单方式 | 数据粒度 | 现状 |
|---|---|---|---|---|
| 51信用卡管家 | 商业 App | 绑定邮箱，在服务器端解析（2012 年起，这类产品的鼻祖） | 明细 + 汇总 | 仍在更新（V12.10.11）；2019 年因暴力催收被查，爬虫取数也受到质疑；主推借贷 |
| 卡牛信用管家 | 商业 App | 早年有邮箱导入、短信解析、网银导入 | 明细 + 汇总 | 仍在更新（9.4.4），但介绍里已不提邮箱导入；主推借款 |
| 随手记 / 挖财 | 记账 App | 早年有邮箱导入和网银导入 | 明细 | 现在以导入微信、支付宝账单为主 |
| 网易有钱 | 记账 App | 邮箱 + 银行接口 | 明细 | 2021-04 停运（2019 年后监管收紧） |
| QQ 邮箱「我的账单」 | 邮箱自带功能 | 邮箱内部自动识别账单邮件 | 只有应还金额和还款日 | 在"体验室"里开启，不能记账 |
| ZhiKaKa-Bills（开源） | Flask + 网页 | 只支持 QQ 邮箱 IMAP | 11 家银行，只提取应还金额 | MIT，2026 年的新项目 |
| bank-bill-extractor（开源） | Python + GitHub Actions | 阿里邮箱 IMAP | 12 家银行，只提取应还金额和还款日 | 仅限个人使用 |
| china_bean_importers（开源） | Beancount 导入器 | 需要手动导出 .eml 或 PDF | 工行、建行、中行、民生能解析**逐笔明细** | MIT；中行、建行的实现可以借鉴（注明出处） |
| deb-sig/double-entry-generator（开源） | Go | CSV/XLS，不解析邮件 | 多家银行的明细 | Apache-2.0 |

**结论**：目前没有一个产品能同时做到"本地运行 + 自动拉取 + 逐笔明细 + 多家银行"。商业产品要把邮箱授权交给第三方，开源项目要么只有汇总，要么需要手动导出。

**隐私提醒**：账单里就是每一笔交易的明细，按《个人信息保护法》属于敏感个人信息。正因为敏感，才要在本地处理。

## 趋势（2026）
- 多家银行在停止邮寄纸质账单：建行 2026-06-20 起，民生 2026-03 起，杭州银行 2026-04-15 起。
- 信用卡专属 App 在并入手机银行：中行"缤纷生活" 2026-06-30 停止服务，邮储 2025-12 起。
- 电子账单邮件仍然在发，但要逐张卡确认已开通"邮件账单"，并且邮件里带明细。

## v1（Gemini 初稿）评审问题的结论
1. **解析健壮性** → [parsing.md](parsing.md#健壮性规则)：终态、找不到就报错、多版本、兜底标"未核实"、按银行配置的缺账单心跳、reparse。
2. **状态机与重试** → [pipeline.md](pipeline.md)：三段幂等、两类错误、三层去重、质量优先级、outbox。
3. **密钥与环境隔离** → [security.md](security.md)：四者分离、SecretStr、数据目录放在仓库外、gitleaks、脱敏时不改金额。
4. **能否导出 Beancount** → [data-model.md](data-model.md)：v1 的模型不够，已补充记账日、交易类型、原币金额、按币种的汇总块（含溢缴款）、合成调整、稳定 ID 和溯源字段。

## 版本历史
- **v1**：和 Gemini 讨论的 "AutoBill-Agent"，规则加 AI 双引擎，推送走企业微信和邮件。
- **v2**（2026-09-18）：第一轮评审。去掉 AI；改为只读游标拉取；修正对账公式；邮件为主、企业微信为辅；先在家里电脑运行。
- **v2.1**（2026-09-18）：第二轮评审。补充风险清单；P3 改成"Oracle 只做中转和看门狗"；回填 12 个月。
- **v3**（2026-09-18）：拿到 5 封真实样本后，按模块拆成多个文档。新增三份银行格式规格；对账改为分项核对并支持合成调整；来源校验按银行配置；记录了脱敏时的字体泄露教训。
- **v3.1**（2026-09-19）：
  - 公开仓库；样本一次性脱敏后定稿到 `tests/fixtures/`，去掉脱敏脚本；

  - 去掉还款提醒，只展示还款日；
  - 报表只做汇总和可视化；币种按账单邮件当天的网上汇率折算成人民币；
  - `parse()` 改为返回列表；新增 `MailSource`、`rebuild` 和 `docs/setup.md`；
  - 增加 `.gitattributes`。
- **v3.2**（2026-09-19）：
  - 新增开发流程文档 `docs/development.md`（面向新手：环境、Git 和 PR、CI、M0–M8 里程碑、测试规范、版本发布、词汇表）和给 AI 看的 `CLAUDE.md`；
