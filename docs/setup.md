# 操作手册（第一次配置）

这些步骤都要**你本人**在邮箱、银行 App 和电脑上操作，程序代替不了。以 QQ 邮箱为例；163 邮箱的差异单独注明。

## 1. 开通银行电子账单（每张卡都要做）
- 在各家银行的 App 里确认已开通**邮件电子账单**，收件地址是你的主邮箱，并且**邮件里带交易明细**（不能只发"账单已出"的通知）。
- 已知的发件人（主邮箱做转发规则时要用）：

  | 银行 | 发件人 |
  |---|---|
  | 农行 | `e-statement@creditcard.abchina.com.cn` |
  | 建行 | `service@vip.ccb.com` |
  | 中行 | `boczhangdan@bankofchina.com` |

## 2. 新开中心邮箱
1. 注册一个新邮箱专门收账单，建议用一个 QQ 小号。地址不要公开。
2. 进入 设置 → 账号与安全 → 安全设置，开启 **IMAP/SMTP 服务**，生成**授权码**。这个授权码只给 AutoBill 用。
   - 注意：修改 QQ 密码会让授权码失效，改完要重新生成。
3. 在 IMAP 设置里勾选**"允许收取自定义文件夹"**，否则程序看不到下一步要建的专属文件夹。
4. 新建文件夹 `CreditCard_Raw`。
5. 新建一条**收信规则**：发件人是上表地址之一，或者主题含"信用卡电子账单""电子对账单"的邮件 → 移动到 `CreditCard_Raw`。
   - 这样银行邮件不会落进会被自动清理的垃圾箱，中心邮箱才能一直作为"原件库"，本机数据丢了可以从这里重建。
6. 把三家银行的发件人加入**白名单**，避免被判成垃圾邮件。
- **163 邮箱**：同样要开启 IMAP 并使用授权码。程序会自动发送 `ID` 命令，你不需要额外操作。

## 3. 主邮箱设置自动转发（新账单）
- 在主邮箱新建收信规则：**发件人是上表地址之一** → 自动转发到中心邮箱。
- **只按银行发件人转发**，不要转发所有邮件。
- 设置好以后，先等一封真实账单被转发过去，确认中心邮箱收到的邮件内容完整（M8 会用这封邮件验证"转发会不会改动原邮件"）。

## 4. 历史账单（只做一次）
- 在主邮箱网页版搜索上面三个发件人，勾选**最近 12 个月**的账单邮件，用"**作为附件**转发"发到中心邮箱。
- **分小批**转发，每次几封就好。一次勾选太多，QQ 会把附件变成"超大附件"，那是一个会过期的下载链接，程序拿不到原件。
- 重复转发没关系，程序会自动去重。

## 5. 本机运行（M8）
1. 用 `uv` 安装 AutoBill。
2. 把中心邮箱授权码存进 Windows 凭据管理器（`keyring`），或者写进 `.env`。**不要写进 `config.yaml`**。
3. 从 `config.example.yaml` 复制出 `config.yaml`，填好中心邮箱地址、主邮箱地址（报表发到这里）、卡的别名等。
4. 先手动跑一次 `autobill run`，确认主邮箱收到了报表。
5. 在 Windows **任务计划程序**里新建任务：
   - 每 15 分钟运行一次 `autobill run`；
   - 选择**"只在用户登录时运行"**，否则读不到凭据管理器里的授权码；
   - 在"设置"里勾选**"如果过了计划开始时间，立即启动任务"**，否则休眠期间错过的运行不会补上。

## 6. 企业微信（以后，可选）
1. 注册企业微信，不需要认证，企业里只有你自己。
2. 创建自建应用，**可见范围只勾选你自己**；记下 corpid、agentid、secret。
3. 在企业微信的"微信插件"里用个人微信扫码关注，之后消息会进入个人微信。
4. 在 Oracle 服务器上：
   - 申请**固定公网 IP**；
   - 部署中转服务；
   - 用"接收消息服务器 URL"完成验证，再把固定 IP 填进"企业可信 IP"。
5. 家里电脑加一个 WireGuard peer，连到 Oracle。
