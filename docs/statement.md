# 标准账单

对应代码：`autobill/report/statement.py`（数据和每日柱状图）、`autobill/report/templates/statement.html.j2`（模板）、`autobill/report/pdf.py`（打印成 PDF）。里程碑 M7b。

## 是什么
农行、建行、中行的账单格式各不相同。解析器已经把它们统一成同一套数据结构（`Bill` / `Transaction`，见 [data-model.md](data-model.md)）。标准账单是在这之上的**渲染层**：**每份账单生成一份统一模板的 HTML 和 PDF，包含全部逐笔流水**。

- 以后会和原始账单、数据文件一起放进 iCloud，作为"用户端"汇总的基础（下一步再做）。
- 它是 AutoBill 自己的文档，**不仿冒银行的品牌或 logo**：标题写"AutoBill 标准账单"，页脚注明"依据银行电子账单生成，金额以银行原账单为准"。
- 邮件正文仍然只做汇总（见 [notify.md](notify.md#账单月进度邮件)），逐笔流水只出现在标准账单里；**进度邮件把新账单的标准账单 PDF 作为附件**一起发到 iCloud 邮箱（M7c）。

## 设计参考
- **美国信用卡账单的法定结构**（CARD Act / CFPB）：付款信息 → 账户摘要（上期 + 新增 − 还款 = 本期）→ 交易明细 → 利息和费用。它和我们的[对账恒等式](data-model.md)一一对应。
- **Apple Card 月度账单**：一个大数字、分类概览、每日消费柱状图。
- **Monzo / Revolut**：交易按天分组，商户下面一行灰色小字写分类、地点、原币金额。
- 视觉规则沿用邮件报表：一个主色（`#2a78d6`）加灰色；文字不用图表的颜色；只用系统字体（苹方 / 微软雅黑）；**没有 JavaScript，不引用任何外部资源**；支持深色模式。

## 版面（从上到下）
1. **抬头**：银行、卡号尾号、账单周期、账单日；对账状态徽章（✓ 对账通过 / ⚠ 对账有警告 / ? 未对账，图标加文字，不只靠颜色）；解析和对账的警告逐条列出。
2. **付款信息**：本期应还（折合人民币）、到期还款日；各币种的应还和最低还款。只写事实，不做提醒。
3. **账户摘要**：每个币种一张小表：上期余额 ＋ 本期新增 － 还款和退款 ± 调整 ＝ 本期余额。余额 = 欠款 − 溢缴款，为负表示有溢缴款。
4. **本期消费**：
   - 大数字：折合人民币，已扣除返现和退款；
   - **每日消费柱状图**：内嵌 SVG，只算消费、手续费、利息、取现，不算返现；只标出最多的一天；
   - 分类横条：前 5 类加"其他"，"未分类"放最后、用灰色。
5. **各类交易**：消费、还款、返现、分期本金、购汇、调整……各自的笔数和合计。
6. **交易明细**：全部逐笔，按交易日分组。每行左边是商户或描述，下面一行灰色小字（分类 · 地点 · 原币金额 · 汇率 · 期数 · 入账日），右边是金额。
   - 还款、返现、退款显示为负数，并带类型标签；
   - 还款、分期本金、购汇、调整标注"不计入支出"；对账补出的调整行标注"银行未列明细，由对账补出"；
   - 只有一个币种时，金额后面不重复写币种，标题里写"金额单位 CNY"；
   - 多张卡合在一份账单时才显示卡号尾号。Apple Pay 的设备卡号在解析时就归入了实体卡，不会出现。
7. **外币与汇率**：折算人民币用的汇率和日期（Frankfurter）、银行的购汇汇率。
8. **页脚**：解析器名和版本、银行邮件日期、生成时间。

## 命令
```powershell
uv run autobill statement --all -o D:\某个目录                   # 数据库里的全部账单
uv run autobill statement --account ABC:0003                      # 这张卡最新的一期
uv run autobill statement --account CCB:0004 --date 2026-06-10 --no-pdf
```
- 文件路径：`<输出目录>/ABC-0003/2026-09-16.html` 和同名 `.pdf`；重复生成直接覆盖，内容只有"生成时间"会变。
- 默认输出目录是 `<数据目录>/statements`，可以在 `config.yaml` 的 `statement.output_dir` 里改。想直接放进 iCloud，就指向 `C:\Users\<你的用户名>\iCloudDrive\` 下面的某个文件夹，iPhone 的"文件"App 里就能打开。

## PDF 怎么生成
- 用本机 **Edge 或 Chrome** 的无头模式，把同一份 HTML "打印"成 A4 PDF（`--headless=new --print-to-pdf`）。所以 PDF 和 HTML 内容完全一致，也不需要额外的 PDF 库。
- 浏览器按这个顺序找：`config.yaml` 的 `statement.pdf_browser` → 常见安装路径 → PATH。找不到就只生成 HTML 并给出提示（CI 上就是这样）。
- 每次用一个临时的浏览器配置目录，不影响你正在用的浏览器窗口。
- Windows 上 Edge 的启动程序会先退出、由子进程继续写 PDF，所以程序会等文件写完（最多 30 秒）再判断成功与否。
- 打印样式：区块尽量不跨页（所以第一页底部可能留白）；每日柱状图限制了高度，免得在 A4 上字被放大。

## 已知限制
- 商户名是银行原文，没有做"去掉渠道前缀"之类的美化（例如"财付通-某某商户"）。
- 深色模式只在 HTML 里生效，PDF 固定是浅色。
- 图表只有每日柱状图和分类横条；跨月、跨卡的分析留给以后的"用户端"。
